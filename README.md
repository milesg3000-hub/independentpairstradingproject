# independentpairstradingproject
Summary: Quantitative pairs trading project comparing VECM cointegration with a dynamic State Space Local Level Model's updates via the Kalman Filter to model relationship between pairs of assets. The state space model was fitted through maximum likelihood and was regularized through Ridge regularization due to a vanishing gradient causing the algorithm to stall at starting parameters using the outer product of gradients (OPOG) in its formulation. Volatility modelling was applied to determine conditional volatility in the trading signals including different models from the GARCH family.
