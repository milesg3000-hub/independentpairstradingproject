# independentpairstradingproject
Summary: Quantitative pairs trading project comparing static VECM cointegration with a dynamic State Space Local Level Model's updates via the Kalman Filter. Features L2 Ridge-regularized MLE, time-varying hedge ratios, GARCH(1,1) volatility scaling, and net transaction-cost backtesting on KO and PEP.

Soon to graduate from my BSc, I sought to practice empirically the financial econometrics and statistical theory I had covered in my degree. I chose a very simple pair of KO and PEP (whose returns have a trivial long-run error correcting relationship) to make it easier to achieve this aim.
